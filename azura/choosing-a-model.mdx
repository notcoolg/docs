A model selector sits above the Omnibox. The models available to you can change over time, so open the selector in the product to see the current lineup — this article explains how the selector behaves rather than listing models.

## Pick a model

1. Click the model selector above the Omnibox.
2. Choose a model from the list.
3. Your choice is remembered between visits.

## Models and attachments

Some models cannot process images or files. When you have an attachment in the conversation:

- The selector marks incompatible models **"Unavailable with current uploads"**.
- If you upload an attachment while using an incompatible model, Azura automatically switches you to a model that supports uploads.

## Switch models with a slash command

You can also switch models from the Omnibox with a `/model` command followed by the model name. Type **`/`** in the Omnibox to see the current command list.

## How quotas work with models

Each model's usage quota runs independently. If you hit a limit on one model, switching to a different model is the immediate workaround. See [Understand usage limits](/azura/usage-limits) for details.
