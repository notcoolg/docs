**Skills** are task-specific procedures for coding, research, writing, analysis, and design. Skills change the work process, not Azura's personality. Multiple skills can be active at once.

## Open Skills

Choose any of these:

- Click the **"Skills"** button above the Omnibox — it opens Settings directly to the Skills tab.
- Click the **Settings** gear in the header and open the **"Skills"** tab.
- Use the `/settings` slash command.

## Built-in skills

The **"Built-in"** section lists the current skill catalog. The catalog changes over time, so check Settings → Skills → **"Built-in"** for the current list. Each skill shows its name, icon, description, and an expandable workflow — use **"Show workflow"** / **"Hide workflow"** to see the steps a skill applies.

## Create a custom skill

1. In Settings → **"Skills"**, click **"New Skill"**.
2. Fill in the fields:
   - **Icon**
   - **Name** — for example, "Release Checklist"
   - **Short Description**
   - **Workflow** — the step-by-step procedure added to Azura's instructions
3. Click **"Create Skill"** (or **"Save Changes"** when editing).

Both **Name** and **Workflow** are required. If either is empty, you see "Name is required." or "Instructions are required."

## Manage active skills

- Active skills appear as chips above the Omnibox. Click a chip to deactivate that skill (tooltip: "{name} — click to deactivate").
- If there are many, the chips overflow into **"+{n} more"** with a **"show less"** option.
- A status note shows **"{n} skill(s) active — relevant workflows will be applied to matching requests."**
