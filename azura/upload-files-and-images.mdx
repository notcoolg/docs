You can attach documents and images to a conversation so Azura can read and work with them.

## Attach a file or image

Choose any of these:

- Click the **+** menu next to the Omnibox and choose **"Upload image"** or **"Upload"** for documents.
- Paste an image from your clipboard directly into the Omnibox.
- Paste a large block of text (25+ lines) — Azura converts it into a `.txt` attachment automatically.

Attachments appear in the conversation as image thumbnails or file chips.

## Limits

Supported file types, size limits, and upload quotas can change over time. The upload picker's error messages always state the current limits, and the context bar above the Omnibox shows your current counts against them.

The stable rules:

- Oversized or unsupported files are rejected with an error stating the exact limit and accepted types.
- Large images may be **automatically compressed** before sending.
- There is a **weekly image limit** and a **per-conversation upload limit**. When you reach one, an error tells you how many uploads remain or that the cap is hit.

## Common upload problems

| Symptom | What it means | What to do |
|---|---|---|
| File rejected as too large | It exceeds the current size limit stated in the error | Compress or split the file |
| File type rejected | The format is not supported; the error lists accepted types | Convert to a supported type |
| Image rejected as too large | It exceeds the image size cap | Resize or compress the image |
| Weekly image limit error | The weekly image quota is used up | Wait for the weekly reset |
| Per-conversation upload limit error | The upload cap for this chat is reached | Start a new conversation |
| "File must be an image" | A non-image was chosen in the image picker | Use the document **"Upload"** option instead |

For more fixes, see [Troubleshooting](/azura/troubleshooting).
