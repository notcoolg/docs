On macOS, use **Cmd** where the shortcuts below say **Ctrl**.

## Global shortcuts

| Shortcut | Action |
|---|---|
| **Ctrl K** | Open the command palette from anywhere |
| **Ctrl S** | Save the current document, jot, or deck immediately |
| **Ctrl F** | Open **Find & replace** in a document |
| **Esc** | Close the command palette, find bar, or presentation |

## Command palette

| Key | Action |
|---|---|
| Arrow keys | Move between commands |
| **Enter** | Run the selected command |
| **Esc** | Close the palette |

## Canvas shortcuts

Work in Envisiondeck slides and inline canvases in notes:

| Shortcut | Action |
|---|---|
| **Ctrl X** | Cut the selected element |
| **Ctrl C** | Copy the selected element |
| **Ctrl V** | Paste |
| **Del** | Delete the selected element |
| **Esc** | Exit presentation mode |

## Presentation shortcuts

| Key | Action |
|---|---|
| Click, **→**, **Enter**, **Space** | Next slide |
| **←** | Previous slide |
| **Esc** | Exit the presentation |

## Envisionjot shortcuts

| Input | Action |
|---|---|
| `/` | Open the block command menu |
| `[[` | Link to another note |
| `#`, `##`, `###` | Heading 1, 2, 3 |
| `-`, `1.` | Bullet list, numbered list |
| `[]` | Task list |
| `>`, `---` | Blockquote, divider |
