Envisiondocs offers two export options, both in the **Export** menu in the toolbar:

- **Print / PDF** — opens your browser's print dialog. Choose a printer, or choose **Save as PDF** if your browser offers it.
- **Download HTML** — downloads the document as a file named `enfusion-document.html`.

## Print or save as PDF

1. Open the document.
2. Click **Export** in the toolbar.
3. Select **Print / PDF**.
4. Use your browser's print dialog to print or save the document as a PDF.

Because Envisiondocs is page-based (A4 sheets), the printed layout matches what you see in the editor.

## Download as HTML

1. Open the document.
2. Click **Export** in the toolbar.
3. Select **Download HTML**.
4. Your browser downloads `enfusion-document.html`.

You can open the HTML file in any browser.

## Limitations

- These are the only two export formats. There is no export to Word, Markdown, or other formats.
- Decks and notes cannot be exported. Export is available for documents only.
