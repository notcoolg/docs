Enfusion includes a shared drawing engine used in two places:

- **Inline canvases** in Envisionjot notes. Type **`/canvas`** to embed one.
- **Slides** in Envisiondeck. Every slide is a canvas.

## Canvas tools

| Tool | What it does |
|---|---|
| **Select** | Pick and move elements |
| **Draw** | Freehand drawing |
| Shapes | Insert a **Box**, **Circle**, **Star**, or **Arrow** |
| **Text** | Click to place text, double-click to edit it |
| **Color** | 10 preset swatches plus **Custom** |
| Font size | 10–72 for text elements |
| **Delete** | Remove the selected element |

In a note, an inline canvas shows an element count, or "Blank visual" when empty, with a **Clear** button that removes everything on the canvas.

## Align elements

Right-click the canvas to open the context menu:

- **Cut** (**Ctrl X**), **Copy** (**Ctrl C**), **Paste** (**Ctrl V**), **Delete** (**Del**)
- **Align**: Left, Center, Right, Top, Middle, Bottom
- **Show grid** / **Hide grid**

The grid uses 20px cells with snapping.

## Smart snapping

As you drag an element, blue dashed guides appear when its edges or center line up with the canvas edges or other elements. Release the mouse while a guide is visible to snap into place.

## Performance tips

Canvases slow down as you add more elements. If a slide or inline canvas feels laggy:

- Zoom out using the zoom control (25%–300%) to work at a comfortable level.
- Split content across more slides or more canvases instead of stacking many elements in one place.
