**Discover** is the template and app gallery in Enfusion. Its heading reads **"Find a better way to make."** and it contains:

- **Explore apps** — cards for the four Enfusion apps.
- **Start from a template** — document templates.
- **Jot templates** — note templates.
- **From your network** — documents shared with you, up to four, with a **View all** link.

## Document templates

| Template | Description |
|---|---|
| **Meeting Minutes** | Agenda, decisions, and action items in one record. |
| **Project Proposal** | Make the case for a project before it starts. |
| **Weekly Status Report** | Progress, blockers, and next steps for the team. |
| **Product Requirements** | Goals, user stories, and requirements for a build. |

## Jot templates

| Template | Description |
|---|---|
| **Daily Standup** | Yesterday, today, and what is in the way. |
| **Meeting Notes** | A lean notes page for a single discussion. |
| **Idea** | Capture an idea before it slips away. |
| **Reading Notes** | Takeaways, quotes, and reactions to what you read. |

## Use a template

1. Go to **Discover**.
2. Pick a template from **Start from a template** or **Jot templates**.
3. The preview modal shows a live preview of the template.
4. Click **Create copy**.

The modal notes: *"Creates a {document|jot} you own and opens it in the editor."* You own the copy and can edit it freely. The template itself is never modified.

Decks have no templates. Every deck starts blank. See [Build and present a deck](/enfusion/decks/build-and-present-a-deck).
