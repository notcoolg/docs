This page covers problems with Enfusion document share links. For general sharing guidance, see [Share a document with a link](/enfusion/documents/share-a-document).

## "This link is no longer active or doesn't exist."

The link was removed by the owner, or it never existed. This is permanent for that link.

**What to do:** Contact the person who shared the document and ask them to create a new link. There is no way to restore a removed link.

## "This link is no longer active."

The link expired after the number of days the owner set, or it reached its maximum view count. This is permanent for that link.

**What to do:** Ask the owner for a new link. The owner can set a longer expiry or a higher view limit when creating it.

## "Wrong password."

The password does not match. Passwords are case-sensitive.

**What to do:**

1. Re-enter the password exactly as the owner gave it, including capitalization.
2. Ask the owner to confirm the password.

Do not keep guessing. There is no password recovery from the shared-link side — only the owner can create a new link or confirm the password.

## I am the owner and my link does not work

1. Open the document and click **Share**.
2. Check **Active shares**. The list shows each link's status, view count, and protections.
3. If the link was removed, expired, or hit its view cap, create a new link with the settings you want.

## Security reminder

Never share your password, authentication codes, backup codes, or session tokens with anyone, including support staff. It is safe to share the share-link URL itself (not its password), the error message text, and the time the problem occurred.

If these steps do not resolve the problem, see [Contact support](/contact-support) to open a ticket.
