**Envisionjot** is the notes app in Enfusion. Notes are built from blocks, so you can mix headings, lists, quotes, code, and drawings in one note.

## Create a jot

1. Press **Ctrl K** (or **Cmd K**) and choose **New jot**, or go to **Discover**.
2. On the **"New jot"** page — *"Start with a thought."* — enter a **Title**. The placeholder is *"Untitled"*.
3. Click **Create jot**.

## Add blocks with the slash menu

Type **`/`** on an empty line to open the command menu:

| Command | Shortcut |
|---|---|
| **Heading 1** | `#` |
| **Heading 2** | `##` |
| **Heading 3** | `###` |
| **Bullet list** | `-` |
| **Numbered list** | `1.` |
| **Task list** | `[]` |
| **Blockquote** | `>` |
| **Code block** | three backticks |
| **Divider** | `---` |
| **Canvas** | `/canvas` |

The **Canvas** command embeds a small drawing surface in your note. See [Use inline canvases](/enfusion/canvas/use-inline-canvases).

## Link notes together

Type **`[[`** to link to another note. These wiki-links connect your notes, and the **Backlinks** sidebar shows which other jots link to the one you are reading.

## Tags and note types

Below the title you find two fields:

- **Tags** — type in the "Add tag..." field and press **Enter**. Tags are lowercased. Remove a tag by clicking the × on its chip.
- **Note type** — a free-text field for sorting your notes, such as daily, meeting, or idea.

## Outline and backlinks

- The **Outline** sidebar lists the headings in your note. If there are none, it shows *"Add headings to build an outline."*
- The **Backlinks** sidebar lists other jots that link to the current note.

## Focus mode

Focus mode hides all interface chrome so only your note remains. To leave focus mode, click the floating **"Exit focus · Esc"** button or press **Esc**.

## Saving

Jots autosave about a second after you stop typing. The status shows **"Saved"** or **"Unsaved"**. Press **Ctrl S** (or **Cmd S**) to save immediately.
