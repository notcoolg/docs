**Enfusion** is a coherent workspace for your work. It brings documents, notes, spreadsheets, and presentations together in one place, so you can keep your work together without ecosystem lock-in.

Enfusion is a web app. You do not need to install anything — open it in a modern browser and sign in with your **Economic ID** account.

## Key features

- **One workspace.** Move between documents, notes, and decks from the same sidebar.
- **Command palette.** Press **Ctrl K** (or **Cmd K**) from anywhere to jump to a page or run a command.
- **Templates.** Start from ready-made templates for documents and notes in **Discover**.
- **Share documents.** Create read-only share links with optional passwords, expiry, and view limits.
- **Light and dark mode.** Switch themes from the top bar or the command palette.

## What Enfusion does not do yet

To set expectations, these features are not available:

- **Excelerate** (spreadsheets) is coming soon.
- Enfusion is web only. There are no native desktop or mobile apps.
- There is no offline mode.
- There is no real-time co-editing. Only you can edit your own work.
- Only documents can be shared with a link. Notes and decks cannot be shared or exported.
- Deleted decks cannot be recovered. There is no trash or recycle bin.
