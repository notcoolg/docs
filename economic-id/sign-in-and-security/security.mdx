## Choose a strong sign-in method

Economic ID supports password sign-in, passkeys, and two-factor authentication with an authenticator app. Use more than one method when possible so you have a recovery option.

## Passkeys

A passkey lets you sign in with a fingerprint, face scan, device PIN, or another supported device authenticator.

<Steps>
  <Step title="Open Security settings">
    Sign in to [Economic ID home](https://id.ecowestern.net/id/home) and open **Security**.
  </Step>
  <Step title="Add a passkey">
    Select the option to add a passkey and follow the device prompts.
  </Step>
  <Step title="Name the passkey">
    Give it a name that helps you recognize the device later.
  </Step>
</Steps>

You can view, rename, and delete registered passkeys from **Security**. Passkey setup is optional, and you can add one later.

<Warning>
  If you lose a device containing a passkey, use another available sign-in method and remove the lost passkey from Security settings. If you cannot sign in, try self-service recovery first. Support recovery is not guaranteed.
</Warning>

## Two-factor authentication

Two-factor authentication uses a time-based verification code from an authenticator app. To set it up, open **Security**, add an authenticator app, scan the QR code, and enter the code shown in your app. If you cannot scan the QR code, use the displayed secret instead.

Economic ID may generate backup codes during setup. Store them securely and do not share them. Follow the recovery instructions shown in Economic ID; do not assume backup codes can restore access until the product confirms that behavior.

## Security reminders

- Enter your password and verification codes only on `id.ecowestern.net`.
- Never share a password, passkey, verification code, or backup code.
- Use a unique password and store it in a password manager.
- Sign out on shared or public devices.
- If you see an authentication error, do not share copied URLs outside an approved support channel.

If self-service recovery does not resolve a security problem, [open a support ticket](/contact-support) through the built-in support system. Include the error details, but not secrets.
