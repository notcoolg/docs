## I cannot sign in

1. Confirm that you are using the official domain: `id.ecowestern.net`.
2. Check your email address and password.
3. Try a passkey if you have registered one.
4. Complete two-factor verification if prompted.
5. Use **Forgot password?** if you cannot remember your password.

Try self-service recovery before contacting support. Recovery is not guaranteed. See [Contact support](/contact-support) for how to open a ticket.

## I see “Continue session?”

Economic ID may show this page when you are already signed in and another EcoWestern product asks to authenticate. Select **Continue** to use the current account, **Use a different account** to switch, or **Go to Economic ID home** to manage the account.

## I am redirected repeatedly

Use the same regular browser window, check privacy settings, and make sure the browser can use the session required by the product. Close extra sign-in tabs and start again from the product you want to open.

## A connected application reports an error

Record the error code, application name, approximate time, device, and browser. If the error page provides **Copy URL**, share the copied URL only through an approved support channel because it may contain sensitive query data.

Never share passwords, authenticator codes, backup codes, passkeys, or session tokens.

## I see “Account unavailable”

The account may have been deactivated. Follow the instructions on the page and submit a support ticket if you believe this is a mistake or need more information. Reactivation or recovery is not guaranteed.

## I cannot access an organization

Confirm that you are signed in with the invited email address and that your invitation has not expired. Contact the organization administrator if you still cannot access the organization.
